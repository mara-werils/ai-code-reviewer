# Security Policy

## How it works

AI Code Reviewer sends your PR diff to the LLM provider you choose (OpenAI, Anthropic, Groq, Google, or your own Ollama instance). **No code is stored** by this tool.

If you need full privacy, use Ollama with a local model -- nothing leaves your network.

## Reporting a vulnerability

If you find a security issue, please email **security@mara-werils.dev** instead of opening a public issue.

We will respond within 48 hours and aim to release a fix within 7 days.

## Supported versions

| Version | Supported |
|---------|-----------|
| v1.x    | Yes       |
| < v1    | No        |
