# Product Hunt Launch Plan

## Listing Details

**Name:** AI Code Reviewer

**Tagline (60 chars max):**
Free AI code review for GitHub & GitLab. Works with any LLM.

**Description:**
AI Code Reviewer adds automated AI-powered code review to your pull requests in 30 seconds. Just add one workflow file — no config needed.

Unlike paid tools ($19/user/month), AI Code Reviewer is 100% free and open source. Bring your own LLM — GPT-4o, Claude, Llama, Gemini, or run 100% locally with Ollama.

**Key features:**
- One-line setup, zero config
- Works with ANY LLM (OpenAI, Anthropic, Groq, Google, Ollama)
- Inline comments with suggested fixes (one-click apply)
- Security checks and risk assessment
- On-demand /review command in PR comments
- GitHub Actions + GitLab CI support
- Self-hosted mode with RAG-powered codebase understanding
- Reviews in 9 languages
- $0.002/review with Groq's free tier

**Topics:** Developer Tools, GitHub, Open Source, Artificial Intelligence, Code Review

**Makers comment (first comment):**
Hey PH! I built AI Code Reviewer because I was tired of paying $19/user/month for AI code reviews. The existing tools are great, but they lock you into their models and pricing.

So I built an open-source alternative that:
- Works with ANY LLM (want GPT-4o? Claude? Local Llama? Your choice)
- Costs ~$0.002/review with Groq (yes, that's a fraction of a cent)
- Sets up in 30 seconds (one YAML file)
- Can run 100% locally with Ollama (your code never leaves your network)

What makes it different from PR-Agent and similar tools:
1. Multi-LLM support out of the box — switch providers with one line
2. /review command — type it in any PR comment to trigger a review
3. Cost estimation — know exactly what each review costs before it runs
4. GitLab support — not just GitHub
5. Self-hosted mode with actual codebase understanding (AST indexing + vector search)

Would love your feedback. What features would make this a must-have for your team?
